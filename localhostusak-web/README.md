# localhostusak-web

Bu klasör, **localhost[uşak]** platformunun React 19 Frontend ve Node.js SQLite Backend servislerini içerir.

Detaylı proje mimarisi, tasarım dili ve çalıştırma adımları için lütfen projenin ana sayfasındaki dokümantasyonu inceleyin:

👉 [**Ana Dokümantasyon & Proje README.md**](../README.md)

### Hızlı Başlatma
```bash
# Bağımlılıkları yükleyin
npm install
npm --prefix server install

# Backend servisini başlatın (Port 3001)
npm run server

# Frontend servisini başlatın (Port 5173)
npm run dev
```
